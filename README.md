# Student Management System

A JavaScript-based Student Management System built using the **Fetch API** and REST API operations. The project demonstrates CRUD functionality including fetching students, retrieving individual records, adding new students, updating student details, partially updating city information, deleting students, and searching students by name.

**Tech Stack:** HTML, CSS, JavaScript, Fetch API, REST API

**Features:** GET • POST • PUT • PATCH • DELETE • Error Handling • Student Search
